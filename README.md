# 新材道电子名片

员工填写个人信息、实时预览并下载电子名片。提供商务版、常规版及中英文样式，支持单张 PNG 或双语 ZIP 下载。

## 使用

打开本仓库对应的 GitHub Pages 网页。姓名、职位、其他信息按中英文分别填写，电话和邮箱共用。个人输入在浏览器中用于生成图片，本页面没有上传员工信息的接口。

## 修改及发布

- 源码在 src，默认公司信息和名片排版在 src/card.js，界面在 src/employee.html 和 src/style.css。
- Logo、二维码在 src/assets。
- 安装 Node.js 后，运行 node build-pages.mjs 重新生成根目录 index.html。
- 将修改后的源码与 index.html 一并提交到 main 分支。
- GitHub Settings → Pages，选择 Deploy from a branch → main → / (root)。
- Pages 完成发布后，新内容会使用同一项目网址。

员工公开页面不提供设计师入口。设计师通过本人 GitHub 私有工作区编辑和发布，详见下方说明。仓库不包含设计师口令或服务器密钥。

## 设计师在线配置（仅本人）

设计师配置台运行在 tingsu92-alt 的 GitHub Codespace 内，使用 GitHub 私有端口访问权限，不在员工公开站提供后台入口。

1. 登录 tingsu92-alt 后，在本仓库 Code → Codespaces 打开已有工作区；首次需创建。
2. 等工作区启动后，在 Ports 中打开「设计师配置（仅本人）」的 8765 端口。
3. 保持端口可见性为 Private，禁止改为 Public。运行环境只接受原仓库和指定账号，其他人复制仓库不会获得原仓库发布权限。
4. 上传素材、修改文案和排版后，点击「保存并发布」。确认后会将模板保存到 templates/published.json，并更新 index.html，提交至 main，触发 GitHub Pages 更新。
5. 发布后刷新员工网页查看结果。修改中请使用模板 JSON 备份，未发布的浏览器修改在刷新后可能丢失。
6. 用完在 GitHub Codespaces 中停止工作区，以节约免费计算额度。工作区运行和存储占用 GitHub 配额，不是无限免费；免费额度用完时应停止使用，不启用付费超额。

设计师工作区需要启动后才能访问，员工网页独立运行，不受工作区开关影响。工作区停止时后台暂不可用，重新启动后可继续配置。请保留工作区；删除前应确认所有更改已推送或备份。

没有另设共用口令。运行期间的页面会话校验值只保存在私有服务内存，未写入公开仓库。代码不会将 GitHub 凭据发送到员工网页或浏览器。
